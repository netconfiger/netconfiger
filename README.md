## What is NetConfiger?

NetConfiger is a Windows networking tool for configuring network distribution through a selected physical or virtual network adapter. It uses a virtual-adapter / TUN-based networking architecture and can expose HTTP and SOCKS5 endpoints for compatible clients and workflows.

## Highlights

- **Choose the source adapter** — use a physical or virtual network adapter as the source for network distribution.
- **HTTP and SOCKS5 endpoints** — provide proxy endpoints for compatible clients.
- **Windows-focused workflow** — configure and manage the networking setup from a Windows PC.
- **Virtual-adapter / TUN architecture** — support network handling through a virtual interface.

> **Scope note:** NetConfiger is not an Ethernet Layer 2 bridge. Do not assume it transparently forwards arbitrary Ethernet frames, broadcasts, or multicast packets.

## Typical setup checklist

1. Install and open NetConfiger on a supported Windows system.
2. Select the intended physical or virtual source adapter.
3. Configure the available HTTP or SOCKS5 endpoint settings.
4. Verify connectivity from the intended client in your own network environment.
5. Confirm firewall rules, DNS behavior, and client proxy support.
