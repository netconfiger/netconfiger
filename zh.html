工作方式

一台 Windows 主机，统一提供局域网入口

NetConfiger 的作用是复用客户已经拥有并管理的网络连接，不提供代理节点、VPN 账号或网络线路。

01 / 准备

连接 Windows 主机

先在 Windows 上连接并确认客户自有的合法授权网络可以正常使用。

02 / 分发

创建 HTTP/SOCKS5 入口

通过局域网可达的地址与端口，向兼容应用提供代理入口。

03 / 使用

配置下游应用

在其他电脑、虚拟机或浏览器工作环境中明确设置代理地址。

适用范围

面向实际 Windows 网络共享场景

适用于 Windows 已连接 SoftEther、PacketiX 等客户端的环境，以及支持手动配置代理的虚拟机和浏览器工作环境。

复用已有网络出口

不需要重复向每台工作电脑部署相同的上游网络客户端。

电脑与虚拟机

在局域网连通、应用支持 HTTP/SOCKS5 的前提下配置使用。

明确产品边界

当前公开版本不是透明整机网关，不承诺所有应用无需设置即可共享网络。
