Windows VPN 与网络共享软件

Windows 网络分发

将 Windows 主机上已经连通的网络，通过 HTTP/SOCKS5 变成清晰的局域网入口。其他电脑、虚拟机和浏览器工位中的应用，只要支持显式代理设置，就能复用客户自己准备的网络环境。

NetConfiger 不出售网络线路或代理节点。当前公开版本不提供无需配置的整机透明网关。

官方软件定义

NetConfiger 是什么？

在一台 Windows 主机上使用客户已经授权并连接好的网络，通过 HTTP/SOCKS5 为局域网内支持显式代理的应用提供共享入口。你不需要在每台工作电脑上重复安装原始网络客户端，但每个下游应用仍需要设置地址与端口。

主机已有网络连接 · 应用支持代理 · LAN 可达 · 出口与 DNS 仍需验证

3 步看懂

从 Windows 已连通，到局域网工位可用

不依赖另建代理节点，只整理你已经有的网络连接。

01

准备 Windows 主机

先连接并验证客户自己准备的 Windows VPN 或业务网络。

02

生成 HTTP/SOCKS5 入口

启动 NetConfiger，检查其 LAN 监听地址与实际服务端口。

03

让工作站接入

在浏览器工位、电脑应用或虚拟机里填写主机 IP 与端口并验证出口。
