01 / HOW IT WORKS

一台 Windows 主机，供多台设备上的应用使用

不出售代理节点，也不提供 VPN 线路；重点是复用客户已经连接的 Windows 网络。

准备主机

先连接并确认 Windows 上已有的网络可正常使用。

建立共享入口

通过 NetConfiger 提供局域网可访问的 HTTP/SOCKS5 地址和端口。

配置客户端

在其他电脑、虚拟机或浏览器工作环境中，为支持代理的应用配置入口。

02 / PRODUCT SCOPE

适用场景与能力边界

适合已有 Windows VPN 客户端、需要让多台工作站复用网络出口的团队。

01

现有 Windows 网络

例如已经连接的 SoftEther / PacketiX 或其他授权网络。

02

电脑和虚拟机

局域网中支持显式 HTTP/SOCKS5 代理设置的应用。

03

能力边界明确

当前公开版本不是整机透明网关，不提供 VPN 账号或网络节点。
