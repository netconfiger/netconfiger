Product definition

What is NetConfiger?

NetConfiger exposes an authorized, already-connected Windows network as HTTP/SOCKS5 LAN endpoints. Proxy-aware applications on nearby PCs and VMs can use that connection without installing the original upstream client on every workstation; each downstream app still needs a host address and port configured.

Connected Windows host · Proxy-aware applications · LAN reachability · Egress/DNS validation
