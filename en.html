01 / HOW IT WORKS

One Windows host, multiple proxy-aware applications

NetConfiger does not sell proxy nodes or VPN lines. It helps reuse a Windows network the customer already manages.

Prepare the host

Connect and verify the authorized Windows network first.

Create a LAN entry

Expose an HTTP/SOCKS5 address and port on the LAN.

Configure clients

Point supported apps on other PCs or VMs at the LAN endpoint.

02 / PRODUCT SCOPE

Practical use cases and product scope

For teams with an existing Windows VPN client that need to reuse the connection across workstations.

01

Existing Windows connections

Such as already-connected SoftEther / PacketiX or other authorized networks.

02

PCs and virtual machines

Apps supporting explicit HTTP/SOCKS5 proxy configuration.

03

Clear product boundaries

The public release is not a transparent whole-device gateway and does not supply VPN accounts or nodes.
